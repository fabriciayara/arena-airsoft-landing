# Arena Airsoft — Landing Page

Landing page de divulgação do Arena Airsoft, um app conceitual pra organizar partidas de airsoft num só lugar (divulgação, inscrição, times e regras), em vez de espalhado por grupos de WhatsApp.

🔗 **No ar:** https://arena-airsoft-landing.vercel.app

Este projeto faz parte do [portfólio de UX/UI design de Yara Fabricia](https://arenaairsoftapp.vercel.app), como exercício de landing page de produto. O Arena Airsoft é um protótipo de estudo, não um aplicativo publicado nas lojas — o [case completo de design](https://arenaairsoftapp.vercel.app/cases/arena-airsoft.html) tem a pesquisa, as decisões e os testes de usabilidade reais por trás dele.

## Stack

HTML e CSS puro, sem framework. Deploy automático via [Vercel](https://vercel.com), a partir deste repositório.

## Estrutura

```
index.html      landing page
styles.css      estilos
```
